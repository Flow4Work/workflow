# FLOW PM KIT

AI와 함께 기획 문서 → 모바일 UX → 웹 확장 → 클릭형 프로토타입 → QA까지 이어가는 PM/PO 작업 키트.

## 핵심
- Mobile First
- Toss-inspired simplicity, not pixel-copying
- 결과 + 주요 판단 이유
- 사실 / 가정 / 확인 필요 분리
- 승인 전 외부 write 금지
- 프로토타입 우선 검증
- GitHub는 Source of Truth
- Vercel 배포 없음

## 사용
OpenCode에서 이 저장소를 clone한 뒤 프로젝트 루트에서 실행한다.

주요 명령:
- `/prd 아이디어`
- `/screen 기능/문서`
- `/prototype 기능/문서`
- `/review 산출물`
- `/qa 대상`

## Workflow
아이디어
→ Product Doc
→ Mobile Screen Spec
→ Web Extension
→ Prototype
→ Senior Review
→ QA
→ 개선
