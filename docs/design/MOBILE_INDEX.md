# Mobile Index

기준: 390×844.

검증:
- 360×800
- 390×844
- 430×932

각 화면은 반드시 다음을 정의한다.
1. 사용자 목표
2. 진입 조건
3. 핵심 정보 우선순위
4. 컴포넌트
5. Primary CTA
6. Secondary action
7. Default
8. Loading
9. Empty
10. Error
11. Permission/locked
12. 다음 화면
13. 분석 이벤트
14. 설계 이유

원칙:
- 1 화면 = 1 주요 목적
- 핵심 CTA 즉시 식별 가능
- 긴 표는 모바일용 리스트/행 구조로 재설계
- 부가 정보는 progressive disclosure
- 입력은 필요한 것부터
- touch target은 충분히 크게
- 가로 스크롤 금지
