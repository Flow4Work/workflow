# Web Index

웹은 모바일 UX의 확장판이다.

기본:
- 1440×900 검증
- content max width는 목적에 맞게 제한
- 읽기형은 중앙 집중
- 작업형은 sidebar / master-detail 허용

Mobile → Web:
- bottom nav → sidebar/top nav
- 1열 → 필요 시 2~3열 또는 master-detail
- full-screen filter → sidebar/popover
- bottom CTA → sticky action 또는 우측 상단
- 입력 + preview 동시 노출 가능

금지:
- 남는 공간을 채우기 위한 카드
- 불필요한 KPI dashboard
- 모바일/웹 메뉴명 불일치
- CTA 분산
