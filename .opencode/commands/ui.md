순서:
1. mobile-screen-spec skill로 390×844 모바일 화면을 먼저 설계한다.
2. 핵심 사용자 플로우와 화면별 Primary CTA를 확정한다.
3. Default / Loading / Empty / Error / Permission 상태를 정의한다.
4. web-extension skill로 모바일 정보구조를 유지하며 1440×900 웹으로 확장한다.
5. prototype skill로 핵심 플로우가 실제 클릭되는 프로토타입을 만든다.

디자인 원칙:
- Toss-inspired: 단순함, 빠른 이해, 명확한 계층, 충분한 여백.
- 특정 Toss 화면을 그대로 복제하지 않는다.
- 불필요한 카드/배너/탭/KPI 박스를 추가하지 않는다.
- 모바일 가로 스크롤 금지.
- Primary CTA는 화면당 원칙적으로 1개.
- 360×800, 390×844, 430×932에서 모바일 사용성을 고려한다.
