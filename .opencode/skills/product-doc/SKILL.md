# Product Document

입력에 맞는 문서 유형을 스스로 선택한다.

공통:
- 목적
- 배경/문제
- 사용자/대상
- 목표
- 비목표
- 요구사항
- 우선순위
- 성공기준
- 리스크
- 오픈 퀘스천
- 다음 액션

PRD 추가:
- 사용자 시나리오
- North Star
- supporting metrics
- guardrails
- Must / Should / Won't
- MVP
- 더 싼 검증법

모든 핵심 판단에는 짧은 이유를 덧붙인다.
없는 숫자나 사실을 만들지 않는다.
