# Prototype

목표는 예쁜 정적 이미지가 아니라 검증 가능한 interaction이다.

기본:
- 390×844 우선
- 360px 가로 스크롤 금지
- mock data/local 우선
- 외부 API 없이 핵심 flow 검증
- CTA, 화면 이동, 입력, 선택, 상태 변화 동작
- 프로토타입임을 표시

Acceptance:
- 핵심 task end-to-end 완료 가능
- dead end 없음
- primary CTA 명확
- 최소 하나 이상의 Empty/Loading/Error 상태 구현
- 실제 외부 write 없음

모바일 검증 후 web responsive 확장을 수행한다.
