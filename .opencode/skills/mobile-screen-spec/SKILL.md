# Mobile Screen Spec

먼저 docs/design/MOBILE_INDEX.md와 docs/design/TOSS_INSPIRED.md를 읽는다.

작업:
1. 핵심 사용자 flow를 3~7단계로 정리.
2. 필요한 화면만 생성.
3. 각 화면의 목적, 정보 우선순위, 컴포넌트, CTA를 작성.
4. Default / Loading / Empty / Error / Permission 상태 정의.
5. edge case와 복귀 흐름 확인.
6. 왜 이 구조인지 설명.
